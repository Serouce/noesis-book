## 1. Ключевые правки после 4-стороннего аудита (что спасло проект до кода)

### А. Инженерно-технический фундамент (Волна 1 — обязательный каркас)
1. **Hash-роутинг вместо `/act-1` (устраняет 404 при `F5`):** маршруты **`#/act-1` … `#/act-5`** + глубокие якоря **`#/act-2?section=ch-4`**, `history.scrollRestoration = 'manual'`, парсер с whitelist + единый хелпер **`assetUrl(relPath)`** на `import.meta.env.BASE_URL` (устраняет все корневые `src="/v..."`).
2. **Запрет GSAP `pin: true` в React 19:** все 4 скролл-сетписа строятся **строго на CSS `position: sticky`** (`overflow-x: clip`) + `gsap.context().revert()` + 4-фазный протокол `switchAct()` (`Lock & Curtain` → `Unmount & Purge` → `Hard Scroll & HUD Reset` → `Lazy Mount, 2× rAF & Reveal`) + `React.lazy` code-splitting 5 Актов (первый экран `≤ 250 КБ raw`, префетч следующего Акта на `70%` скролла).
3. **Zero-Reflow HUD + `useViewportRaf` + `usePsychophysicsClock`:**
   * `syncHudFromViewport()` вызывается только при изменении `scrollY/scrollHeight` (dirty-check вместо 120 reflow/сек) и читает декларативные `data-hud-theme` / `data-hud-immersive`.
   * **`useViewportRaf`** останавливает любой Canvas при выходе за вьюпорт или сворачивании вкладки (`0%` фоновой нагрузки CPU/GPU).
   * **`usePsychophysicsClock`** калибрует реальный VSync экрана (60/120/144 Гц по 12 кадрам `rAF`), считает экспозицию строго по `performance.now()`, отбраковывает пробы с `dt > 45 мс` или сменой вкладки и полностью работает по `Pointer Events` (без зависимости от клавиши `Space`).
   * **HiDPI Canvas-стандарт (`noesisCanvasKit.ts`):** `dpr = Math.min(devicePixelRatio, 2)`, `ctx.setTransform(...)`, `canvas.width = canvas.height = 0` на unmount (защита iOS Safari от OOM), `0px ctx.shadowBlur` (запрет неона!), шрифт строго `JetBrains Mono`, полная поддержка `prefers-reduced-motion` и запрет вспышек `> 3 Гц`.
4. **Отказоустойчивый `localStorage` (`noesis_v9_state_v1`):** `try/catch` + версионированный валидатор/deep-merge + debounce `300 мс` с flush на `pagehide` + синхронизация вкладок (`storage` event) + честная precondition-маска в `consistency` (никогда не хвалит за пропущенные главы!) + реальный спойлеробезопасный URL при шаринге.
5. **Чистка мёртвого груза:** удалить неиспользуемые `three`, `@react-three/*`, `d3-*`, `motion` из `package.json` и мёртвые архивные фото из `public/`.
